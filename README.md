# Hi, I'm Matthew

Geomatics student at the University of Waterloo (Computing minor). I make projects with hardware, software and firmware, and I turn location data into maps and decisions.

**→ Portfolio: [sheetmars.github.io](https://sheetmars.github.io)**

### Selected work
- **[Tracking wildfire forest loss with Sentinel-1 radar](https://sheetmars.github.io/projects/sar-wildfire-quebec/)**: six years of SAR in Google Earth Engine over northwestern Quebec
- **[Sensor drivers to orientation on a Nordic Thingy:53](https://sheetmars.github.io/projects/thingy53-sensors/)**: register-level I2C drivers on Zephyr, fused into roll, pitch and heading ([code](https://github.com/sheetmars/thingy53-sensors))
- **[GPS and temperature field logger](https://sheetmars.github.io/projects/gps-data-logger/)**: Arduino logger plus a Python pipeline from raw NMEA to a local ENU frame ([code](https://github.com/sheetmars/gps-data-logger))
- **[Where should the next fire station go?](https://sheetmars.github.io/projects/fire-station-coverage/)**: network analysis of response times in Waterloo Region
